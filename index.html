สถาปัตยกรรมคลาวด์เอกชนแบบ Zero-Knowledge (Zero-Knowledge Private Cloud)

ความปลอดภัยสูงสุด: ผู้ให้บริการคลาวด์ไม่มีสิทธิ์เข้าถึงหรืออ่านข้อมูลดิบได้เด็ดขาด (Zero Knowledge)

1. Client-Side Encryption (ต้นทาง)

ข้อมูลคดี, ผู้ต้องหา และบัตรประชาชน ถูกเข้ารหัสด้วย AES-256-GCM บนเครื่องของ สภ.บางพลี ก่อนส่งออกนอกสถานี

2. Blind Cloud Relay (คลาวด์ตาบอด)

เซิร์ฟเวอร์คลาวด์เอกชนทำหน้าที่เป็นเพียงตู้เซฟเก็บ Ciphertext โดยไม่มีกุญแจถอดรหัส (Zero-Knowledge) แม้คลาวด์ถูกแฮกก็ไม่รั่วไหล

3. Station Key Custody (กุญแจอยู่ที่ สภ.)

กุญแจถอดรหัส (Master Key) ถูกเก็บรักษาอย่างปลอดภัยภายใน สภ.บางพลี เท่านั้น เจ้าหน้าที่ที่ยืนยันตัวตนถูกต้องจึงจะถอดรหัสอ่านได้

⚡🛡️

การควบคุมสิทธิ์เข้าถึงข้อมูล Cyber Invest: โครงการ newpolice อนุมัติเป็นรายคน

ระบบคัดกรองและอนุมัติสิทธิ์เจ้าหน้าที่ตำรวจจากโครงการ newpolice ตามคำขอรายบุคคล

🔒 นโยบายความมั่นคง: เจ้าหน้าที่ newpolice แต่ละนายต้องได้รับอนุมัติจากแอดมินก่อนจึงจะเข้าถึงข้อมูลคดี สภ.บางพลี ได้
คำขอ / เวลา ผู้ขอ (newpolice) สังกัด วัตถุประสงค์ สถานะ & Token คำสั่งแอดมิน
📝 แบบฟอร์มขอเชื่อมต่อเข้าถึงข้อมูลสารสนเทศสืบสวน (โครงการ newpolice)

จำลองหน้าจอสำหรับเจ้าหน้าที่ตำรวจจากโครงการ newpolice เพื่อส่งคำขอเข้าถึงข้อมูลมายัง สภ.บางพลี เพื่อรอให้แอดมินอนุมัติ

🔍 ทดสอบการยิง Query ดึงข้อมูลด้วย Clearance Token

ระบบจำลองการเรียกใช้งาน API /api/external/newpolice/query-cyber-invest โดยเจ้าหน้าที่ newpolice: หากยังไม่ได้รับอนุมัติจะถูกปฏิเสธ (403 Forbidden) แต่หากอนุมัติแล้วจะสามารถเข้าถึงข้อมูลคดีและบัญชีม้าได้

กดปุ่ม "ยิงทดสอบ API" เพื่อดูผลการตอบกลับจากระบบความปลอดภัย
