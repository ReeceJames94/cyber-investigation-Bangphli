# ระบบสนับสนุนงานสืบสวนสอบสวนคดีออนไลน์ (Cyber Investigation Portal) - สภ.บางพลี

โครงสร้างโปรเจกต์เวอร์ชันแยกโมดูล (Modular Architecture) เพื่อให้พัฒนา แก้ไข และต่อยอดฟีเจอร์ได้ง่าย เป็นระเบียบ ไม่ซับซ้อน

---

## 📁 โครงสร้างโฟลเดอร์และไฟล์ (Project Structure)

```text
cyber-investigation-portal/
├── index.html                  # ไฟล์โครงร่างหน้าเว็บหลัก (Semantic HTML + Modals)
├── css/
│   └── style.css               # สไตล์กำหนดเอง (Custom CSS, Fonts & Scrollbar)
├── js/
│   ├── config.js               # การตั้งค่า Firebase / Cloud Firestore
│   ├── state.js                # จัดการข้อมูลกลาง (State, LocalStorage & Cloud Real-time Sync)
│   ├── ui.js                   # ฟังก์ชัน UI (แจ้งเตือน Toast, กล่องยืนยัน, สลับโหมดมืด/สว่าง, สลับแท็บ)
│   ├── app.js                  # จุดเริ่มต้นระบบ (Bootstrap, Login/Logout, Global Shims)
│   └── modules/
│       ├── cases.js            # ระบบจัดการฐานข้อมูลเคสคดีออนไลน์ (ค้นหา, ตัวกรอง, เพิ่ม/แก้ไข/ลบ)
│       ├── warrants.js         # ระบบลิสต์หมายจับ & ติดตามสถานะจับกุมและส่งสำนวน
│       ├── inquiry.js          # ระบบเช็กลิสต์ประเด็นคำถามสอบสวน (14 ประเภทกลโกง)
│       ├── reports.js          # ระบบช่วยร่างแบบฟอร์มรายงานสืบสวนราชการ
│       ├── knowledge.js        # คลังระเบียบ ข้อกฎหมาย และเอกสาร PDF
│       ├── users.js            # ระบบจัดการบัญชีผู้ใช้งาน และสร้างลิงก์ซิงค์
│       └── export.js           # ระบบพิมพ์/ส่งออกรายงานคดีและหมายจับเป็นเอกสารทางการ
└── README.md                   # คู่มือโครงสร้างโปรเจกต์
```

## 🚀 วิธีเปิดใช้งาน (How to Run)

1. **เปิดผ่านเบราว์เซอร์โดยตรง (Direct Open):**
   - ดับเบิลคลิกไฟล์ `index.html` เพื่อเปิดใช้งานใน Chrome, Edge, Safari หรือ Firefox ได้ทันที โดยไม่ต้องติดตั้งโปรแกรมเสริมใดๆ

2. **เปิดผ่าน Local Web Server (แนะนำสำหรับการพัฒนา):**
   ```bash
   # หากมี Node.js
   npx serve .
   
   # หรือใช้ Python
   python -m http.server 8000
   ```

## 🧩 คำอธิบายหน้าที่ของแต่ละไฟล์ใน `js/`

| ไฟล์ | หน้าที่หลัก |
|---|---|
| `config.js` | ตั้งค่า API Key และเชื่อมต่อ Firestore Database (`cyber-bangphli`) |
| `state.js` | เก็บข้อมูลตั้งต้น, แคชข้อมูลออฟไลน์ใน `localStorage`, ซิงค์ `onSnapshot` ขึ้น/ลง Cloud |
| `ui.js` | หน้าต่างแจ้งเตือน Toast สวยงาม, Modal ยืนยันลบข้อมูล, การแปลงไฟล์ PDF เป็น Base64 |
| `cases.js` | เพิ่ม/แก้ไข/ลบเคส, กรองตามวันที่/สถานะ, จัดการบัญชีม้าคนร้ายหลายแถว, ติ๊กหมายเรียก/หมายจับ |
| `warrants.js` | ติ๊กสถานะจับกุม/ส่งสำนวน, แนบไฟล์ PDF บันทึกจับกุมและดาวน์โหลด |
| `inquiry.js` | ดึง 14 หัวข้อกลโกง, เพิ่มคำถามสอบสวนใหม่, ลบคำถามที่ไม่ต้องการ |
| `reports.js` | รวมฟิลด์อัตโนมัติสร้างเอกสารบันทึกข้อความราชการ สภ.บางพลี พร้อมปุ่มคัดลอก |
| `knowledge.js` | คลังระเบียบ พ.ร.ก. และการอัปโหลดไฟล์ PDF เข้าระบบ |
| `users.js` | เพิ่มผู้ใช้พร้อมเช็คชื่อซ้ำ, การแชร์ลิงก์ `sync_users` ให้เจ้าหน้าที่คนอื่น |
| `export.js` | สร้างหน้าต่างพิมพ์เอกสารสวยงามแบบ Responsive สำหรับสั่งพิมพ์หรือเซฟเป็น PDF |
| `app.js` | ตรวจสอบ Session ล็อกอิน, รวม Event Handlers เพื่อความเข้ากันได้กับ HTML |
